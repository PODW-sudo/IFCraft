# Legacy Editing Tools Archive (v1)

This directory contains the archived implementation of the original v1 editing tools:
- `ContextualModifyBar.v1.tsx` (Legacy contextual ribbon bar)
- `SelectionContextOverlay.v1.tsx` (Legacy in-canvas selection overlay)

These were archived on 2026-10-07 prior to the implementation of the industry-grade CAD/BIM Editing Suite inspired by **Archicad 29** (Pet Palette & Tracker HUD) and **Tekla Structures 2025** (Two-Point Precision Reference Move/Copy & Move/Copy Special).
