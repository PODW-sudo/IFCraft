# IFC Editor — Production Readiness & Architectural Recommendations

This document consolidates all concrete, actionable recommendations across architecture, 3D WebGL performance, parametric CAD compliance, real-time collaboration, security, and code hygiene for the IFC Editor codebase.

---

## 1. Architecture & State Decomposition (`frontend/src/App.tsx`)

* **Extract the "God Controller":** `App.tsx` currently orchestrates nearly 50 React state hooks and over 35 components[cite: 4]. High-frequency actions (such as mouse movement during a CAD drag or 60 FPS gizmo transform) risk triggering full-tree React reconciliation.
* **Decompose into Specialized Hooks/Stores:**
  * `useModelLifecycle`: Manages project loading, IFC parsing state, federation sub-model lists, and Web Worker lifecycles[cite: 3].
  * `useSpatialSelection`: Manages selected `GlobalId` / `expressID` sets (`Set<string>` for $O(1)$ lookup), hover states, and bi-directional tree/inspector sync[cite: 3].
  * `useCadDraftingMachine`: Implements a finite state machine (`IDLE` $\rightarrow$ `SELECTING_BASE_POINT` $\rightarrow$ `TRACKING_VECTOR` $\rightarrow$ `COMMITTING`) to replace boolean soup in CAD toolbars and HUDs[cite: 3].
  * `useGizmoTransform`: Decouples transient 60 FPS `TransformControls` drag deltas from root React state, updating HUDs via refs and committing to backend REST/WebSocket only on mouse-up[cite: 3].
* **Fix HMR Error Ring Memory Leaks:** Guard the global `console.error` patch and window error listeners with a singleton flag (`__IFC_ERROR_TRAP_INSTALLED__`) to prevent recursive stacking during Vite HMR re-evaluations[cite: 4].
* **Stabilize Event Callbacks:** Wrap `handleSelectElement` in `useCallback(..., [])` using persistent refs (`elementLocksRef`, `selectedExpressIDRef`) to prevent unnecessary event listener re-binding on remote lock broadcasts[cite: 4].

## 2. 3D WebGL & Web Worker Performance (`ThreeViewport.tsx` & `ifcWorker.ts`)

* **Deterministic VRAM Disposal:** Implement recursive object traversal (`disposeObject3D`) on project switch and component unmount to dispose geometries (`geometry.disposeBoundsTree()`, `geometry.dispose()`), multi-material arrays, and canvas textures[cite: 1].
* **Zero-Copy Worker Buffers:** Ensure `ifcWorker.ts` transfers flat `Float32Array` and `Uint32Array` buffer instances via the `transfer` list of `postMessage(payload, [positions.buffer, normals.buffer, indices.buffer])` to eliminate Structured Clone overhead[cite: 1, 4].
* **Shared Worker Request Queuing:** Avoid spawning brand-new `IfcWorker` instances per sub-model upload (`App.tsx`)[cite: 4]; instead, route parse requests through a single shared worker instance utilizing correlation IDs.
* **BVH Spatial Indexing:** Build a Bounding Volume Hierarchy (`three-mesh-bvh`) on loaded IFC geometries to keep raycasting and point-snapping under $1\text{ ms}$ even on complex models[cite: 1, 4].
* **Instanced & Batched Rendering:** Group identical IFC type occurrences (doors, windows, columns) into `THREE.InstancedMesh` or category-based `THREE.BatchedMesh` nodes to reduce WebGL draw calls by up to $90\%$[cite: 1, 4].
* **Section Cut Capping:** Implement stencil-buffer or capping geometry for active orthogonal section planes so cut geometry appears solid rather than hollow[cite: 4].

## 3. Parametric CAD & IFC Standards Compliance (`ifc_service.py` & `cad_service.py`)

* **World vs. Local Placement Correction (`ifc_service.py`)**: Replace direct overrides of `ObjectPlacement.RelativePlacement` with `ifcopenshell.api.run("geometry.edit_object_placement", model, product=entity, matrix=M, is_si=True)` to correctly resolve parent `PlacementRelTo` reference chains and apply SI-to-project unit conversions[cite: 1, 3].
* **Fix Mirror Matrix Implementations (`cad_service.py`)**: Correct the X and Y axis mirror functions, which currently apply identical rotation matrices instead of proper reflection transformations[cite: 3].
* **Fix Deleting Openings & Fillings (`cad_service.py`)**: Replace the incorrect attribute lookup `rel_fill.RelatedOpeningElement` with `rel_fill.RelatedBuildingElement` inside `delete_element` to prevent runtime `AttributeError` when deleting walls containing doors/windows[cite: 3].
* **Parametric Wall Geometry Updates (`cad_service.py`)**: Ensure `update_geometry` modifies the underlying wall extrusion depth and profile rather than only writing metadata property sets[cite: 3].
* **BCF 2.1 Standard Compliance (`bcf_service.py`)**: Serialize 22-character Base64 `GlobalId` strings into `IfcGuid` attributes inside `viewpoint.bcfv` instead of integer STEP `#express_id` values[cite: 3].

## 4. Real-Time Collaboration & Concurrency (`websocket_manager.py` & `websocket.py`)

* **Fix Room Lock-Wiping Bug (`websocket_manager.py`)**: Remove the unconditional clearing of `self.locks` when `len(self.sessions) <= 1` in `remove_user`, as it inadvertently destroys active locks held by the sole remaining user when a teammate disconnects[cite: 3].
* **Enforce Soft-Lock Validation on Commit (`websocket.py`)**: Validate that `room.locks.get(express_id)["user_id"] == current_user_id` before processing `TRANSFORM_COMMIT` or writing placement changes to disk[cite: 3].
* **Asynchronous File Persistence**: Offload synchronous disk I/O (`model.open` / `model.write`) inside WebSocket handlers to background threads (`asyncio.to_thread`) to prevent blocking the FastAPI event loop during live collaborative drags[cite: 3].
* **Lease-Based TTL & Heartbeats**: Attach 15-second TTL expiration leases and periodic ping/pong heartbeats to active locks so network drops purge zombie locks automatically[cite: 1].

## 5. Security & Input Validation (`federation.py`, `projects.py`, `ai_service.py`)

* **Path Traversal Sanitization (`federation.py`)**: Wrap uploaded sub-model filenames with `Path(file.filename).name` combined with UUID prefixes to prevent directory traversal attacks[cite: 1, 3].
* **Unbounded Memory Upload Protection (`projects.py`, `federation.py`)**: Replace memory-buffering `await file.read()` calls with chunked streaming limits (e.g., max $250\text{ MB}$) and verify the `ISO-10303-21;` magic header before parsing[cite: 3].
* **SSRF and Query Key Leak Mitigation (`copilot.py`, `ai_service.py`)**: Restrict `base_url` inputs in AI copilot configurations to prevent internal network requests (SSRF), and eliminate passing secret API keys through URL query parameters[cite: 3].
* **XML Escaping in BCF Exporter (`bcf_service.py`)**: Wrap all text elements in `markup.bcf` with `xml.sax.saxutils.escape()` to guarantee well-formed XML archives[cite: 3].
* **Parametric Generation Parameter Clamping (`ai_service.py`)**: Clamp `num_storeys` in `_exec_generate_building` (e.g., $\max 50$) to prevent CPU exhaustion and denial-of-service from runaway generative prompts[cite: 3].

## 6. Testing, Quality Gates & Design System

* **Maintain the 366-Test QA Harness**: Continue executing the key functionality tier (`--tier key`) on every code modification and run the full milestone suite before releases using `qa_runner.py` via Chrome DevTools Protocol[cite: 3].
* **DTCG Design Token Discipline**: Ensure all UI components and views strictly import `design-tokens.css` and use `var(--token-name)` CSS variables with zero hardcoded color literals[cite: 2, 3].
